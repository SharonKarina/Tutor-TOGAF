# Corpus local

Copia aquí los extractos PDF de TOGAF que tienes autorización para procesar. Los
documentos se leen en el equipo local para extraer texto, crear fragmentos y calcular
embeddings. Esta carpeta está excluida de Git porque los PDF suministrados indican
“Evaluation Copy. Not for redistribution”.

Archivos localizados para este proyecto:

- `TOGAF_V9.1-Introduccion.pdf`
- `TOGAF_V9.1-FasePreliminar.pdf`
- `TOGAF_V9.1-VisionArquitectura.pdf`
- `TOGAF_V9.1-ArquitecturaNegocio.pdf`
- `TOGAF_V9.1-ArquitecturaInformacion.pdf`
- `TOGAF_V9.1-ArquitecturaAplicaciones.pdf`

No subas estos archivos a GitHub. En la interfaz desplegada, cada usuario carga los
documentos desde su propio dispositivo para procesarlos dentro de la sesión.
